How it works

Three moves, in order.

  1. 1

    Keep a useful view

    Furl selects a transformation for the content. Depending on the input, it can retain relevant lines, compact rows, or offload a large payload with a structured overview. Check the original before relying on omitted details.

  2. 2

    Fold the duplicates

    Repeated lines and near-identical rows collapse into a compact marker that records how many were removed and under which hash. The marker is small, readable, and honest about what it stands for.

  3. 3

    Retrieve on demand

    Stored text can be recovered byte-exact; structured JSON can be re-serialized while preserving its values rather than its original spacing. Retention, eviction, redaction settings and storage availability affect what can be retrieved.

The honest read

What is real today, and what is not yet.

Today

The Python API, CLI and MCP tools compress content and retrieve stored details. This page replays historical captures from version 1.2.0; the current package is version 1.4.0. These results are not a promise for every input.

Automatic

Automatic hooks are client-specific. ChatGPT uses explicit MCP tool calls; it does not run Claude Code hooks or automatically intercept other plugins. See the connection guide and the repository limits.

Bounds

These captures are repetitive machine output, the case furl is built for. On high-entropy prose the honest range is lower, roughly zero to 54 percent. Some inputs are left unchanged; omitted details require retrieval.

furl is context compression for AI agents. It can reduce active token usage by producing compact views with retrievable stored details. Savings depend on the input and model; retrieval depends on retention and storage availability. Use it as a Claude Code plugin, Codex plugin, or standalone MCP server.
