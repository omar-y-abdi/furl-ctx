Support and accessibility

Report a bug

Open a Furl GitHub issue with the package version, operating system, installation method, reproduction steps and sanitized error output. GitHub issues are public. Never include API keys, OAuth tokens, signed download URLs or private traces.

Private questions

For privacy requests or sensitive reports, use the maintainer contact rather than a public issue. For security reports, follow the repository's security policy. There is no guaranteed response-time service level.

Connection help

A website URL is not automatically an MCP endpoint. Read Connect Furl for the difference between local stdio, a private Secure MCP Tunnel and a public authenticated HTTP deployment.

Accessibility

The site provides a skip link, keyboard-operable demo tabs, visible focus indicators, a static no-JavaScript table and reduced-motion support. Arrow keys, Home and End navigate the demo tabs. Report the affected URL, browser, assistive technology and steps when something is difficult to use. Automated testing does not establish complete accessibility conformance.
