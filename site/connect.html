Connect Furl

Local CLI, library and MCP

Install Furl in your own environment using the repository instructions. The stdio MCP entrypoint is:

python -m furl_ctx.ccr.mcp_server

This starts a local MCP process, not a public web server. Never expose a local workspace or shared CCR database directly to untrusted users.

Private ChatGPT connection

OpenAI's Secure MCP Tunnel can connect a running local MCP process to your authorized ChatGPT workspace. Keep the tunnel runtime key private, use the tunnel's supported client and verify its readiness before registering the connection. See OpenAI's tunnel guide.

ChatGPT invokes Furl tools explicitly. Furl does not intercept all other ChatGPT tool outputs, delete earlier chat messages, or run Claude Code hooks inside ChatGPT.

Attachments are not server paths

For a ChatGPT attachment, use the declared file input. The host transfers a provided-file reference and Furl fetches it out of band. file_path refers only to the MCP server's local workspace, not the ChatGPT sandbox. Do not paste a large file into model context or invent a download URL.

Public HTTP deployment

This static website does not itself provide a public MCP service. The repository's remote server requires a configured OAuth authorization server, a durable mounted data directory, a public HTTPS origin and per-user isolation. See the remote deployment guide. A route that returns HTML, a health check, or a configuration error is not a working MCP connection.

Before a Directory submission

Verify the live OAuth login and PKCE flow, token validation, user isolation, retention and deletion, real attachment handoff, tool annotations and domain verification. Review the privacy policy, terms and support information. Do not submit a local tunnel URL as a public production endpoint.
