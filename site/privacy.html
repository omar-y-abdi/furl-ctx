Privacy policy

Updated 14 September 2026

Scope and contact

This policy covers this Furl showcase website, maintained by Omar Yusuf Abdi. For privacy questions or deletion requests, use the maintainer contact. Do not post personal or confidential information in public issues.

Visiting this website

The demonstration uses prerecorded public fixtures. This website does not accept uploads, provide user accounts, run a live compression service, or store your conversation. Its code sets no cookies and uses no analytics, advertising pixels, session replay or third-party embeds. Fonts and demonstration assets are served from this website.

Hosting and technical information

Vercel hosts the website and receives technical request information, such as IP addresses, requested URLs, browser information and timestamps, to deliver and protect the service. This is distinct from application-level analytics. Vercel's processing, international transfers and retention depend on its service terms and the project configuration; this website does not create an additional visitor database. See Vercel's privacy policy and data processing terms.

Using Furl locally or through a private tunnel

The CLI, library and local MCP server run wherever you install them. Inputs and stored originals remain in that configured environment unless an integration transmits them elsewhere. A ChatGPT attachment is transferred by the host for processing by the MCP server; this is not a local-only data flow. The model provider and tunnel provider have their own terms.

CCR retention is configurable. Entries can expire, be evicted or be purged; a retrieval marker is not permanent storage. The repository documents the current defaults and deletion behavior. Disconnecting a plugin is not the same as deleting its stored entries. Use furl_purge on the intended entry or store, and manage local databases and backups separately.

Support and public contributions

Contacting the maintainer can disclose your address and the information you choose to send. It is used to respond to and resolve the request. GitHub issues and contributions are public and are processed by GitHub under its privacy statement. Please remove secrets and unrelated personal data before sharing a reproduction.

Your controls

You can request access, correction or deletion of personal information held by the maintainer using the contact above. Support correspondence is kept only while needed to resolve and follow up the request or meet a legal obligation. The maintainer does not sell support data or use it for advertising. You can also complain to your data protection authority; in Sweden this is IMY.

Hosted MCP service

This website is not currently the privacy notice for a public multi-user Furl service. Before such a service accepts data, the operator must publish its identity provider, hosting location, storage and backup retention timelines, subprocessors and deletion controls. The remote deployment guide records these launch prerequisites.
