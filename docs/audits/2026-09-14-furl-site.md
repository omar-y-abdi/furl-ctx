## Local evidence

Python 3.12.14, Rust/Cargo 1.95.0, Ruff 0.16.2, Mypy 1.14.1,
MCP SDK 1.30.0, Playwright 1.57.0 and axe-core 4.10.3.
Package acquisition used the approved GitHub Actions artifact bridge. Python
verification used `PIP_NO_INDEX=1`; native checks used `CARGO_NET_OFFLINE=true`.
Tokenizer and eight parser libraries were restored from dependency artifacts.

- `pytest tests --tb=short -q`: **3034 passed, 1 skipped**.
- `PYTHONPATH=deploy/remote pytest deploy/remote/tests/test_remote.py tests/test_mcp_remote_metadata.py -q`: **21 passed** (four also belong to the root suite).
- `ruff check .`, `ruff format --check .`: passed.
- `mypy furl_ctx --ignore-missing-imports`: 73 source files, passed.
- `mypy deploy/remote/furl_remote --ignore-missing-imports`: seven source files, passed.
- Static website `unittest`: nine contracts, passed.
- Browser suite: seven routes at each of two widths, no reported axe violations,
  JS/asset failures or third-party requests; six demo workflows at each width,
  keyboard navigation, reset race, no-JS and reduced-motion checks passed.
- Repository-equivalent `cargo fmt --all --check`, `cargo clippy --workspace --locked -- -D warnings`, and `cargo test --workspace --locked`: passed; **862 Rust tests**.

An additional, stricter `cargo clippy --workspace --all-targets -- -D warnings`
finds existing deprecated `criterion::black_box` benchmark usage and test-only
loop/closure warnings. The repository's actual CI omits `--all-targets`.
Rust sources/manifests are byte-unchanged from the base; those unrelated warnings
were not hidden or rewritten as part of a website/MCP transport change.

Regression-first checks exposed the reset animation race, mobile Connect hiding,
invalid JWT numeric-claim error, bounded-worker behavior, volatile database fallback
and missing challenge configuration before the corresponding fixes were applied.
Storage tests use real native/stdio workers, not a stand-in compression engine.
Docker needs a daemon absent from the chat sandbox; the added GitHub CI job builds
and exercises the actual image, including a network-disabled native storage smoke.
Hosted CI and Vercel preview results must be checked on the final published SHA;
this document is not a substitute for those check statuses.

## Public launch gates that a commit cannot supply

The Vercel project is `furl-ctx` (`prj_j6vwCfIlnxQ5vMk4xEQYzWPZ7fdz`), static root
`site/`. Its existing ignored-build step correctly skips commits without site
changes. The feature PR must be previewed; main/production are not changed by
local verification or PR creation.

Remote launch requires a real approved container host/persistent volume, HTTPS
origin, OAuth provider/client registration, domain-verification token and hosted
privacy/backup/deletion policy. Test two real accounts, token refresh, restart,
purge and the user's actual 33 MB ChatGPT attachment through the real endpoint.
No anonymous shared database, invented credentials, public fake endpoint or
placeholder SaaS/privacy promise is included. No paid infrastructure was created.
